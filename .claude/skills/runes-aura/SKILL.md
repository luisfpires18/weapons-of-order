## Authority

Do not invent a Rune, fusion result, corrupted/purified Rune, rarity, color, uniqueness rule, class name, or forced weapon transformation.

The creator's newest explicit decision overrides older drafts and implementation.

If a point is unresolved, preserve it as WIP/configurable rather than completing the pattern yourself.

## Critical separations

- Rune vs Runestone.
- Rune family vs Rune identity.
- Weapon category vs Aura Level.
- Runeforging vs mastery awakening.

## Core progression

`L0 Dormant -> L1 Conduit -> L2 Aspect -> L3 Dreadform / Ascendant`

Category ceilings:
- Enhanced -> max L1.
- Artifact -> max L2.
- Chaos/Order -> max L3.

Basic Runeforging can physically reshape a weapon at L0 when its Rune family has an established conditioned form.

That transformation can also replace the wielder's ordinary combat class immediately from L0. A Mystic Staff wielder is Wizard-style from L0. If the transformed class is incompatible with Mounted, remove Mounted.

Do not invent L3 combat behavior yet.
